# Roblox source mirror

Roblox saves places as binary `.rbxl` files that don't diff or merge, so the place file
itself is gitignored. This folder is the **text mirror** of every Luau script in the place,
kept so the game logic is reviewable in git (and visible to judges reading the repo).

One person owns the place file. When a script changes in Studio, mirror it here.

## World geometry

The warehouse shell, the nine bay prefabs, the catwalks, the pallet racks and the sky rails
were generated procedurally from `Config` (bay pitch, wall height, side margin and so on), but
they were generated by **one-off command-bar scripts that were not kept**. Right now that
geometry exists only inside the `.rbxl`, which is the one part of the project git cannot see.

Two consequences worth knowing before you touch it:

- Changing a layout value in `Config.lua` will **not** move existing geometry. The bays are
  baked. Only code that reads `Config` at runtime (`HazardManager`, `SkyArm`, `BlockSync`)
  follows it.
- `BlockSync.cellToWorld` deliberately reads the `Cell_c_r` anchor parts baked into each bay
  rather than recomputing positions, so the baked geometry stays the single source of truth
  for where a crate actually goes.

Re-extracting a generator into `build/` is an open task.

## Reference

`BROKER-2-so-101-teleop-arm-2.3mf` in the repo root is the printable SO-101 teleop arm. The
link lengths in `SkyArm.lua` (`L1 = 6.2`, `L2 = 5.69`) come from measuring `Upper_arm_SO101`
and `Under_arm_SO101` in that model, so the in-game arm has the real robot's proportions.
